Local adaptations use host-native tools, repository instructions and existing
project checks. They do not require gstack binaries, its browser, telemetry,
review ledgers, external models, automatic issue filing or automatic updates.
Review and QA default to reporting; repairs follow the user's request.
Ship follows repository release automation and never adds agent co-authorship.
Careful is advisory in every host; no enforcement hooks are installed.

Maintenance: review upstream changes selectively, update authored skills and
this reference revision together, and recheck discovery and representative
workflows on Claude Code, OpenCode and Cursor CLI. Preserve this notice and
the license when redistributing the adapted collection.
