This is a locally maintained adaptation, not an upstream pstack installation.
The reference revision identifies the source reviewed, not an installed runtime.

Source mapping at that revision:
  SKILL.md (Create)    -> skills/create-verification-skill/SKILL.md
  SKILL.md (Maintain)  -> skills/maintain-verification-skill/SKILL.md
  references/feature-map-example.md
                       -> skills/create-verification-skill/references/
                          feature-map-example/README.md and create-note.md

Local adaptations merge the create and maintain skills into one, generate
.claude/skills/verify-<app>/ instead of a Cursor path, require a helper script
rather than host browser tools as the recipe, keep runs away from the user's
real data and credentials (run-scoped locations checked by doctor, a free
port per run, killing only the recorded process group, asking before mutating
when isolation is impossible), extend an existing verify skill instead of
replacing it, stop on a broken checkout instead of fixing product code, limit edits to the working tree with no branch, PR
or commit, and leave the generated skill untracked for the user to share or
keep local. The feature map example is condensed and uses a helper script.

Other pstack ideas adapted into this collection are listed in
../NOTICE.txt. Preserve this notice and the license below when
redistributing.
