This is a locally maintained adaptation, not an upstream pstack installation.
The reference revision identifies the source reviewed, not an installed runtime.

Source mapping at that revision:
  SKILL.md -> skills/correct/SKILL.md, with the fallback rule from
              skills/principle-encode-lessons-in-structure/SKILL.md

Local adaptations add agent session transcripts as evidence and host hooks as
an enforcement level for mistakes in agent behavior, and route each mistake
class to the current repository or the user's global agent setup. Upstream
sets disable-model-invocation; here the agent may load the skill after a
repeated correction, but then only fixes that mistake and proposes its
enforcement, and the full workflow needs an explicit /correct. The skill
follows this collection's scope rules (no commits, read-only modes report)
and drops the expiry-date and human-approval requirement on exceptions.

The architecture examples, the scoping rule for written instructions and the
order of work for common mistakes follow Lauren Tan's talk "All Code Is Slop
(Except Mine)" (https://ai.engineer/talks/O_zcc6Xl12g-all-code-is-slop-except-mine).
