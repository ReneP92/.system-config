              agents/comment-sicko.md

Local adaptations replace the Comment Sicko subagent with a classification
brief for this collection's read-only fresh-eyes-reviewer, so the main session
applies every edit. They keep a "why" the code cannot carry, TODOs with an
owner or issue, every comment a tool reads (including example output and
doctests, where upstream keeps only formatter pragmas), and comments whose
keep status is uncertain, where upstream deletes on doubt. Unverifiable
constraint comments stay; constraint comments whose enforcement the user
declines stay. The scope covers comments a diff adds or changes, untracked
files and comments the change made wrong on touched symbols. Bare TODOs are
reported as open work. Non-trivial reshapes, root-cause fixes, suppression
changes and new checks are proposals that need approval. A verification step
runs lint, type checks, tests and doc builds, treats a drop in tests run as a
regression, and restores a comment rather than suppressing a broken check.

../NOTICE.txt. Preserve this notice and the license below when
redistributing.
